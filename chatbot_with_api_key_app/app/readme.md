how to use:

1.double click the NGPT_chat.exe

2.first time only: Enter your api key

&nbsp;. you can get one in https://gapgpt.app/platform-v2/tokens

&nbsp;. new accounts get $0.5 free credit

3.start chating

QUICKNOTE : this app is built on GPT-4o

====================================================================================================

### &nbsp; COMMANDS

====================================================================================================

/exit - close the app

/clear - clear the screen

/save - save conversation to file

/newkey - change your api key

/help - shows the list of commands

/stats - see usage statistics

====================================================================================================

#### &nbsp; PRIVACY

====================================================================================================

. your api key is only stored in your computer

. app creator (aka nima) cannot see your api key

. no data is sent to anyone except OpenAi

====================================================================================================

#### &nbsp; TROUBLESHOOTING

====================================================================================================

. if you get an error, type /newkey to re-enter your API key

. make sure you have internet connection

. check your gapgpt account has credits left
